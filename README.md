# Lucky Jump

Прототип простої гіперказуальної гри для мобільного Android / APKPure.

## Ідея гри

- Назва: **Lucky Jump**
- Жанр: нескінченна аркада / тапер
- Мета: торкнись екрану, щоб стрибнути, збирай монети та уникай падіння.
- Монетизація: банерна реклама, міжсторінкова реклама після завершення гри, відеореклама за продовження.

## Чому ця ідея підходить

- Легко запускати і грати однією рукою.
- Короткі раунди підвищують залучення.
- Гіперказуальні ігри добре монетизуються рекламою.

## Файли у цьому репозиторії

- `index.html` — основна сторінка з грою.
- `style.css` — стилі для інтерфейсу.
- `script.js` — логіка гри.

## Як розгортати

1. Відкрий `index.html` у браузері, щоб протестувати гру.
2. Щоб зробити APK, упакуйте цю вебгру у WebView за допомогою:
   - Apache Cordova
   - Capacitor
   - або Android Studio + WebView
3. Додайте SDK реклами:
   - AdMob для Android
   - Unity Ads або AppLovin за бажанням

## Як додати рекламу

- `bannerAd` у `index.html` — замініть на реальний банер SDK.
- `watchAdBtn` у `script.js` — тут буде виклик відеореклами для продовження гри.
- Після кожного програшу показуйте міжсторінкову рекламу.

## Наступні кроки

- Додати анімацію та звуки.
- Зберігати рекорди та найкращі результати.
- Додати щоденні нагороди та лідери.
- Зібрати APK та викласти на APKPure.
