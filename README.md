# Lucky Run 3D

Прототип простої 3D гри для мобільного Android / APKPure.

## Ідея гри

- Назва: **Lucky Run 3D**
- Жанр: нескінченний раннер на трьох смугах
- Мета: міняй смуги, уникай перешкод і збирай монети.
- Монетизація: банерна реклама, відеореклама за продовження, міжсторінкова реклама після програшу.

## Чому ця ідея підходить

- 3D графіка робить гру цікавішою.
- Гра проста для керування на мобільному: торкнись лівої або правої частини екрану.
- Короткі раунди добре підходять для монетизації рекламою.

## Файли у цьому репозиторії

- `index.html` — головний інтерфейс та підключення Three.js.
- `style.css` — стилі для сторінки і HUD.
- `script.js` — логіка 3D гри, генерація перешкод, збір монет.

## Як розгортати

1. Відкрий `index.html` у браузері, щоб протестувати гру.
2. Щоб зробити APK, упакуйте цю вебгру у WebView з:
   - Apache Cordova
   - Capacitor
   - Android Studio + WebView
3. Додайте SDK реклами для Android:
   - AdMob
   - Unity Ads
   - AppLovin

## Як додати рекламу

- `bannerAd` у `index.html` — замініть на реальний банер.
- `watchAdBtn` у `script.js` — замініть на показ відеореклами.
- Додайте міжсторінкову рекламу після програшу.

## Наступні кроки

- Додати звуки та ефекти.
- Зберігати найкращий результат у localStorage.
- Додати меню та налаштування звуку.
- Зібрати APK та викласти на APKPure.
